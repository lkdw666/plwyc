# 排列五预测器

基于历史开奖数据的多特征加权模型，用于排列五（前四位）的投注方案生成、预算分配与回测分析。Python + Tkinter 图形界面。

---

## 目录结构

```
排列五预测器/
├── predictor.py          # 主程序：预测模型 + 预算分配 + 回测引擎 + GUI 界面
├── db_utils.py           # 数据库读取工具
├── quant.py              # 量化分析引擎（多因子权重学习 + 回测指标）
├── sync_data.py          # 数据同步脚本（全量/增量拉取 zhcw.com 开奖数据）
├── custom_config.json    # 用户自定义策略配置文件
├── quant_output.json     # 量化分析输出结果
├── app.ico               # 程序图标
├── 运行.bat              # 一键启动 predictor.py
├── 每日同步.bat           # 每日增量同步数据
├── setup_task.ps1         # Windows 计划任务配置（每日 22:00 自动同步）

```

## 主要功能

### 数据获取
- 优先从本地 MySQL 数据库 `pl5_predictor` 读取历史开奖数据
- 数据库不可用时自动回退到 zhcw.com API 爬取
- 提供独立的数据同步脚本 `sync_data.py`，支持全量拉取和每日增量

### 预测模型（Predictor 类）
基于四种特征加权打分，每位 0-9 各得一个综合分：
- **长期频率**（50 期）：数字出现频率
- **短期热度**（近 10 期）：近期活跃度
- **遗漏值反弹**：距今未出期数，越久权重越高
- **一阶马尔可夫转移概率**：上一期同位置数字 → 本期可能数字

### 推荐方案（六种玩法）

| 玩法 | 说明 |
|------|------|
| 二定单码 | 选 2 个位置，每位置定 1 个数字 |
| 二定包码 | 选 2 个位置，每位置包多个数字（拆分为多注单码，每注 0.1 元） |
| 三定单码 | 选 3 个位置，每位置定 1 个数字 |
| 三定包码 | 选 3 个位置，每位置包多个数字 |
| 四定单码 | 4 个位置各定 1 个数字 |
| 四定包码 | 4 个位置各包多个数字 |
| 二现 / 三现 / 四现 | 选 N 个数字，不论位置，全部出现在开奖号中即中 |

> **排序规则**：包码和现码的数字从小到大排列（因为每注都会买一遍，顺序不影响结果），定码始终按位置固定输出（不可排序）。

### 预算分配
- **标准模式**：三档风险偏好（保守 / 平衡 / 激进），每种偏好有预设的玩法分配比例
- **自定义模式**：用户自行勾选玩法、配置包码位数、手动指定现玩法数字；采用等分预算 + 最小正额度 + 剩余二次分配算法，确保每个已勾选玩法至少分到一份投入

### 回测引擎
- 滚动窗口回测，对比算法选号与随机选号的表现
- 输出总收益、ROI、各玩法命中率、逐期明细
- 结果存入 MySQL 数据库 `backtests` / `backtest_details` 表

### 量化分析（quant.py）
- 11 因子模型：3 种频率 + 遗漏 + 一/二阶马尔可夫 + 跨位置共现 + 奇偶/大小反弹 + 和值趋势 + 周期
- 滚动窗口学习各因子的 IC（信息系数），Bayesian 加权得到最优权重
- 全量回测输出 Sharpe、Calmar、最大回撤、盈亏比、胜率等量化指标
- 结果写入 `quant_output.json` 供 GUI 展示

### 数据同步（sync_data.py）
- 分页爬取 zhcw.com 开奖数据并写入 MySQL
- 两种模式：全量同步（`python sync_data.py 5000`）和每日增量（`python sync_data.py --daily`）
- 配套 `每日同步.bat` 和 `setup_task.ps1`（以管理员身份运行可注册 Windows 每日 22:00 自动同步计划任务）

## 快速开始

### 1. 环境准备
```bash
pip install pymysql requests
# 量化功能额外需要（可选）
pip install numpy
```

### 2. MySQL 数据库
- 创建数据库 `pl5_predictor`（字符集 utf8mb4）
- 首次运行 `sync_data.py` 会自动建表
- 默认连接参数：`host=localhost, user=root, password=root`

### 3. 同步历史数据
```bash
python sync_data.py 2000    # 拉取最近 2000 期
```

### 4. 运行主程序
```bash
python predictor.py
# 或直接双击 运行.bat
```
- 输入预算金额、选择风险偏好
- 点击 **预测** 生成推荐方案
- 可选：勾选「启用自定义策略」→ 点击「配置...」个性化设置
- 点击 **回测** 查看算法 vs 随机的滚动回测对比
- 选择数据量后点击 **量化** 运行多因子权重学习与量化报告

## 扩展方向

- **新增特征**：在 `Predictor` 中加入和值、跨度、连号等统计特征
- **机器学习**：用 XGBoost/LightGBM 替换当前的线性加权模型
- **界面美化**：可引入 `customtkinter` 或迁移到 PyQt/Web 前端
